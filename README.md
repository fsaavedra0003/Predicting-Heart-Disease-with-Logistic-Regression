# ❤️ Heart Disease Prediction using Logistic Regression

This project uses logistic regression to predict the presence of heart disease based on patient attributes such as age, sex, cholesterol, chest pain type, etc.

## 📊 Features

- Data preprocessing (encoding, scaling, NaN handling)
- Logistic Regression Model
- Evaluation metrics (accuracy, confusion matrix, classification report)
- Visualizations (feature importance, confusion matrix, target distribution)

## 🧠 Tech Stack

- Python
- Pandas & NumPy
- Scikit-learn
- Matplotlib & Seaborn
